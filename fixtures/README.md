# Test fixtures

Only **synthetic** or **approved de-identified public** DICOM data may be committed here, used in the demo or CI, or shipped in the npm package. Never add files from real patients.

## `synthetic/`

Generated by `npm run fixtures` (`scripts/make-synthetic-fixtures.mjs`). Pixel data is a computed test pattern; identifiers are fixed placeholders (`SYNTHETIC^PHANTOM`, `SYNTH-0001`) and UIDs are derived deterministically under the `2.25` root. Re-running the script produces byte-identical files.

| Path | Content | Transfer syntax |
|---|---|---|
| `single/intraoral-explicit-le.dcm` | 640×480 12-bit intraoral pattern (gradient, grid, disc, "L" orientation marker) | Explicit VR Little Endian |
| `codecs/intraoral-jpeg2000-lossless.dcm` | Same pattern | JPEG 2000 lossless (1.2.840.10008.1.2.4.90) |
| `codecs/intraoral-jpegls-lossless.dcm` | Same pattern | JPEG-LS lossless (1.2.840.10008.1.2.4.80) |
| `stack/ct-001…012.dcm` | 12-slice 128×128 CT sphere phantom; file names run opposite to slice position to exercise geometric ordering. A bar in the top-left corner grows with slice index. | Explicit VR Little Endian |
| `invalid/not-dicom.txt` | Plain text | — |
| `invalid/truncated-pixel-data.dcm` | Valid header, pixel data cut short | Explicit VR Little Endian |

The three intraoral files share one study (series 1–3); the truncated file belongs to that study as series 9. The CT stack is a second study.
