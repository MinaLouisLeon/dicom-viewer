# Test fixtures

Only **synthetic** or **approved de-identified public** DICOM data may be committed here, used in the demo or CI, or shipped in the npm package. Never add files from real patients.

## `synthetic/`

Generated by `npm run fixtures` (`scripts/make-synthetic-fixtures.mjs`). Pixel data is a computed test pattern; identifiers are fixed placeholders (`SYNTHETIC^PHANTOM`, `SYNTH-0001`) and UIDs are derived deterministically under the `2.25` root. Re-running the script produces byte-identical files.

| Path | Content | Transfer syntax |
|---|---|---|
| `single/intraoral-explicit-le.dcm` | 640×480 12-bit intraoral pattern (gradient, grid, disc, "L" orientation marker) | Explicit VR Little Endian |
| `codecs/intraoral-jpeg2000-lossless.dcm` | Same pattern | JPEG 2000 lossless (1.2.840.10008.1.2.4.90) |
| `codecs/intraoral-jpegls-lossless.dcm` | Same pattern | JPEG-LS lossless (1.2.840.10008.1.2.4.80) |
| `stack/ct-001…012.dcm` | 12-slice 128×128 CT sphere phantom; file names run opposite to slice position to exercise geometric ordering. A bar in the top-left corner grows with slice index. | Explicit VR Little Endian |
| `damaged-stack/ct-001…006.dcm` | 6-slice CT phantom (series 2 of the CT study); slice 4 (`ct-004.dcm`) has its pixel data cut short, so it fails to decode while the rest of the series displays | Explicit VR Little Endian |
| `cbct/cbct-001…064.dcm` | 96×96×64 CT phantom, 0.4 mm isotropic, axial (LPS). Air, a soft-tissue cylinder, a bone horseshoe "dental arch" in the middle third of slices (open posteriorly), a bone cube at the patient's right-anterior-superior corner and a bone sphere at the left-posterior-inferior corner, so every axis has a visible direction. File names run opposite to slice position. | Explicit VR Little Endian |
| `cbct-multiframe/cbct-enhanced.dcm` | The same phantom as one Enhanced CT multi-frame file (64 frames). Orientation, pixel spacing, window and rescale in the Shared Functional Groups; per-frame positions in the Per-Frame Functional Groups. Frames are stored superior first (the reverse of the classic series). | Explicit VR Little Endian |
| `cbct-missing-slice/cbct-001…016.dcm` (no 009) | 16-slice 64×64 version of the phantom with slice 9 left out; must be rejected for 3D as `missing-slices` and still open in 2D | Explicit VR Little Endian |
| `invalid/not-dicom.txt` | Plain text | — |
| `invalid/truncated-pixel-data.dcm` | Valid header, pixel data cut short | Explicit VR Little Endian |

The three intraoral files share one study (series 1–3); the truncated file belongs to that study as series 9. The CT stack (series 1) and the damaged stack (series 2) form a second study. The three CBCT series (1 classic, 2 enhanced, 3 missing slice) form a third study.
